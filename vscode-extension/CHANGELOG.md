# Change Log

All notable changes to the "next-intel" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [2.0.0] - 2026-05-18

### Added
- **Real-Time Semantic Intelligence**: Deep integration with Next.js Knowledge Packs (rendering modes, target runtimes, and hydration boundaries).
- **Rich Hover Feedback**: Render full Markdown panels including "Why It Matters", Architecture/Optimization recommendations, and visual examples directly inside your editor.
- **Knowledge-Driven Quick Fixes**: Dynamically generated code actions populated straight from constraint pack definitions in the lightbulb menu.
- **As-You-Type Diagnostics**: Highly responsive debounced diagnostics tracking in-memory unsaved documents.
